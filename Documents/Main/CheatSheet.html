Example Code Block

Use this reusable HTML structure to create code blocks with syntax highlighting and a copy button. Simply change the language and replace the example code with your own.

JavaScript 

    <div class="code-block">

        <div class="code-block-header">
            <span class="code-language">JavaScript</span>

            <button class="copy-code" type="button">
                <i class="bi bi-clipboard"></i>
                Copy
            </button>
        </div>

        <pre><code class="language-javascript">
            // here goes my code
        </code></pre>

    </div>
