Architectural Modeling In Blender Part 1

Add a plane for reference

In order to model our house, we will need to insert a plane for reference in our project.

Insert the plane in blender

  1. Tab → Object Mode ↔ Edit Mode, make sure you are in Object Mode
  2. Shift + A
  3. Image → Mesh Plane
  4. Select Image

Ensure texture is being shown

if the plane does not show any texture it must mean it is not beign show in Material preview

To fix this follow the next steps:

  1. Click Z
  2. Click Material Review
  3. Rotate the plane (R + Y + (Degress)

Scale the plane to real metrics

To ensure we are modeling our house with proper scale size, we must configure our projects to have a correct metric, and transform our Plane so that it fits that scale.

Ensure the units are correct

To ensure we are modeling our house with proper scale size, we must configure our projects to have a correct metric, and transform our Plane so that it fits that scale. We will go to:

  1. Scene → Units → Unit System → Metric
  2. Scene → Unit Scale → 1.0

Create a single vertex

Next we will need to create a line, that we will use as a reference for scaling our plane

  1. Shift + A → Mesh → Plane
  2. Tab → Edit mode
  3. A
  4. M → At Center

Scale the plane reference

Our next step will be scaling the plane so that it matches our reference. by extruding our point so that it fits any wall

Hint: we can use G → Shift+Z. To exclude the Z axis in our transformation

  1. E → To extrude, for example 5.2 cm
  2. Scale the plane

Modeling the walls

We will now begin by modeling the foundation of the house, removing, the vertex line we created and start doing the walls.

Remove the line vertex

We will remove the line vertex from our project, since we all we wanted from it was a correct scale reference.

Add a plane in a corner

We will and now a plane in a corner so that we can start extruding from that point.

From now on we will start extruding from that point, until we fill the house walls. It is important to follow the next points

  1. put planes in corners
  2. extrude a new extension on windows and doors

Extrude the height of the walls

for our next step we will extrude up our walls, excluding doors and windows.

Extrude up our walls

We will only select our walls faces and extrude them in Y axis.

Extrude up our doors to 3/4 hight of the walls

We will only select our walls faces and extrude them in Y axis.

Extrude up our windows to 1/4, 2/4, and 1/4 of the walls

We will only select our windows faces and extrude them in Y axis.

Delete faces of our doors and windows

We will only select the faces of our doors and windows and then press x, and select faces.

Refill the gaps in our windows

Removing our faces will leave gaps in the windows which we need to fill. for this we will follow the next steps:

  1. Edit Mode → Click 2
  2. Select our edges → F
