Architectural Modeling In Blender Part 1

Add a plane for reference

In order to model our house, we will need to insert a plane for reference in our project.

Insert the plane in blender

  1. Tab → Object Mode ↔ Edit Mode, make sure you are in Object Mode
  2. Shift + A
  3. Image → Mesh Plane
  4. Select Image

Ensure texture is being shown

if the plane does not show any texture it must mean it is not beign show in Material preview

To fix this follow the next steps:

  1. Click Z
  2. Click Material Review
  3. Rotate the plane (R + Y + (Degress)
