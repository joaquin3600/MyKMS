Architectural Modeling In Blender Part 1

Add a plane for reference

In order to model our house, we will need to insert a plane for reference in our project.

Insert the plane in blender

  1. Tab → Object Mode ↔ Edit Mode, make sure you are in Object Mode
  2. Shift + A
  3. Image → Mesh Plane
  4. Select Image

Ensure texture is being shown

if the plane does not show any texture it must mean it is not beign show in Material preview

To fix this follow the next steps:

  1. Click Z
  2. Click Material Review
  3. Rotate the plane (R + Y + (Degress)

Scale the plane to real metrics

To ensure we are modeling our house with proper scale size, we must configure our projects to have a correct metric, and transform our Plane so that it fits that scale.

Ensure the units are correct

To ensure we are modeling our house with proper scale size, we must configure our projects to have a correct metric, and transform our Plane so that it fits that scale. We will go to:

  1. Scene → Units → Unit System → Metric
  2. Scene → Unit Scale → 1.0

Create a single vertex

Next we will need to create a line, that we will use as a reference for scaling our plane

  1. Shift + A → Mesh → Plane
  2. Tab → Edit mode
  3. A
  4. M → At Center

Scale the plane reference

Our next step will be scaling the plane so that it matches our reference. by extruding our point so that it fits any wall
