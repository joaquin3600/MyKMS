Architectural Modeling In Blender Part 2

Install Archimesh

in order to put our windows and doors we will require the extension Archimesh

Install Arquimesh

For this step we will install Arquimesh so follow the next steps.

  1. Edit -> Preferences -> Get extensions
  2. Search Arquimesh
  3. Install
  4. Ensure Arquimesh is active in Add-ons
  5. Arquimesh will now appear as a create tab in object mode

Add our doors in Arquimesh

We will now begin to add our doors to our project

Add the door

When placing a door, we want to make a few steps to helps us.

  1. We will set snaping to Edge center
  2. Shift + Right click To set our cursor at the edge center
  3. Click + Door option
  4. Adjust the position of our door or window

The same process wil be done for our windows.
